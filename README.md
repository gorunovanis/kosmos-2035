# Космоконтур 2035 — цифровой контур планирования снабжения топливного узла

Решение кейса «Топливный космоконтур 2035» (КосмоХакатон 2026, Санкт-Петербург). Оператор орбитального топливного узла задаёт резервы мощности, отборы, инвестиции и запас; ядро пересчитывает дневной материальный баланс 2034–2040, платежи, проверки ограничений, сравнивает сценарии и выгружает результаты. Один расчётный контур обслуживает интерфейс, командную строку, тесты и выгрузки.

**Рекомендуемый план: S1 (Earth-Core + Earth-Flex + ZBO с 2036 + опцион Earth-New под 24 месяца).** PV расходов 2035–2040 при 7 % — 9 293 млн в BASE; подготовленный под обязательный стресс вариант тех же контрактов — 10 907 млн без дефицита; CAPEX 540 млн. Числа: `docs/numbers.md`, обоснование: `docs/zapiska.md`.

## Быстрый старт (локально, без интернета и ключей)

```bash
pip install -r requirements.txt
python -m pytest -q                       # 27 тестов: V01–V10, независимый контроль, граничные, интерфейс
python -m streamlit run app/streamlit_app.py
```

Откроется `http://localhost:8501`. Версии: CPython 3.11–3.13, pandas ≥ 2.2, streamlit ≥ 1.40, plotly не требуется (графики Altair из комплекта Streamlit), openpyxl для XLSX. Проверено на Python 3.13.14, Windows 11.

Тот же расчёт без интерфейса:

```bash
python run.py run --plan configs/plans/S1_new24.json --scenario BASE --out results/demo
python run.py run --plan configs/plans/S1_new24_stress_prepared.json --scenario MANDATORY_STRESS
python run.py vectors                   # контрольные векторы организатора V01–V10
python tools/make_results.py              # пересобрать results/ целиком
```

## Данные, допущения, сценарии

Условия организатора (`data/case`) не редактируются; статус CASE_INPUT. Решения команды — планы в `configs/plans`. Допущения — `configs/assumptions.yaml` с именем, значением, единицей, основанием и областью (A1–A14), они же в выгрузке `assumptions.csv`. Сценарии: BASE и MANDATORY_STRESS организатора, LOW/HIGH из `demand.csv`, TEAM-сценарии рисков и гео-событий на копиях. Стресс не смешивается с high и гео без явного правила.

## Границы прототипа

Агрегированная модель одного узла и совместимого топлива; равномерные дневные потоки внутри года (партии запусков не моделируются); 365-дневный учебный календарь; коэффициенты потерь и цены — учебные; срок ввода ZBO и доступность Earth-каналов в подготовительном 2034 году — допущения (A7, A10); reliability используется только в блоке рисков как фиксированные события, Монте-Карло не применяется; выручка и стоимость срыва миссий не считаются. Интерфейс однопользовательский, без авторизации; проверенные размеры набора: 5–6 источников, 6–7 лет, до 2 555 дней. Реестр допущений и вопросы организатору — в записке §4.
